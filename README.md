# Тайнопись — 3D-комикс

Интерактивный 3D-комикс «История самого гениального изобретения» для творческого задания по русскому языку: путь шифра от спартанской скиталы и шифра Цезаря до Энигмы, открытого ключа и квантовых компьютеров.

**Смотреть:** https://nurmukasan.github.io/comics/

## Что внутри

- **Книга комиксов в 3D.** Обложка лежит на столе, книга открывается, страницы перелистываются в 3D. Камера ведёт от кадра к кадру, как в цифровых комиксах; остальные кадры страницы приглушаются.
- **Листание по шагам.** Одно нажатие — одна анимация до конца: стрелки ↓ ↑ (или → ←, пробел, PageDown — удобно с пультом), кнопки внизу, колесо мыши (один жест — один шаг) или свайп на телефоне. Номер шага пишется в адрес: ссылка `…/comics/#12` открывает 12-й шаг.
- **16 страниц:** обложка, «Действующие лица», 13 глав, задняя обложка. Общие планы, крупные планы, звуковые надписи («ХВАТЬ!», «ЩЁЛК!»), пузыри реплик, жёлтые подписи рассказчика.
- **Пузыри как в печатных комиксах:** реплика, крик-звезда, облако мысли, шёпот пунктиром, плашка рассказчика; ключевые слова красным, слова проявляются по одному. Пузыри сами подбирают размер и не выходят за край кадра.
- **Живые персонажи.** Полуреалистичная манга: пропорции живого лица, тени растровыми точками, штрих гравюры. Герои моргают, водят глазами, открывают рот, когда говорят, поворачивают голову и поднимают руки по ходу скролла.
- **Реалистичный 3D-бюст Цезаря** на обложке и в финале: three.js и настоящий скан головы с гравюрным шейдером. Бюст поворачивает голову за курсором или наклоном телефона.
- **Интерактив:** свой сдвиг Цезаря, кнопка «Держи, чтобы прочесть», частотный анализ аль-Кинди, перебор ключей, шифр Виженера, рабочая Энигма (роторы I–III, рефлектор B), разложение 3233 на множители, шифровка своего имени.
- **Речевое сопровождение:** текст на 2 минуты для двух выступающих и режим «Суфлёр». Стрелки и пробел листают кадры — удобно с пультом.

## Как сделано

- `js/art.js` — персонажи из частей (тело, голова, лицо, руки) и окружение, всё в SVG.
- `js/fx.js` — фильтры печати: штрих гравюры и полутон из бесшовной плитки (feTile), отдельный фильтр на каждый кадр.
- `js/pages.js` — страницы, кадры, шаги чтения, реплики и виджеты.
- `js/book.js` — движок книги: листы, 3D-перелистывание, камера, пошаговое листание, подписи, оживление персонажей, звук.
- `js/bust.js` — 3D-бюст (three.js, модель `assets/3d/head.glb`).
- `trailer/` — трейлер в HyperFrames: `capture.mjs` снимает книгу покадрово, `score.py` синтезирует звук.

## Запуск локально

```bash
python3 -m http.server 8000
```

## Пересборка трейлера

Трейлер собран в HyperFrames из покадровой съёмки самой книги. Нужны Node.js, playwright и ffmpeg.

```bash
cd trailer
node capture.mjs http://localhost:8000/
python3 score.py
npx hyperframes render -o ../assets/trailer.mp4
```
