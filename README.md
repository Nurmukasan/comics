# Тайнопись

Интерактивный комикс «История самого гениального изобретения» для творческого задания по русскому языку: путь шифра от спартанской скиталы и шифра Цезаря до Энигмы, открытого ключа и квантовых компьютеров.

## Что внутри

- **13 кадров**, которые сменяются при прокрутке (свайпе) вниз. Сцены переходят друг в друга через красный круг, который проходит через весь комикс.
- **Рисунок кодом**: SVG и самодельный фильтр «гравюра». Чем темнее участок, тем толще штрих, а линии слегка «кипят», как на видео-референсе.
- **Интерактив**: свой сдвиг Цезаря, кнопка «Держи, чтобы прочесть», частотный анализ аль-Кинди, перебор 25 ключей, шифр Виженера, рабочая Энигма (роторы I–III, рефлектор B), разложение 3233 на множители, шифровка своего имени.
- **Речевое сопровождение**: текст на 2 минуты для двух выступающих, режим «Суфлёр» показывает реплики под текущим кадром. Стрелки и пробел листают кадры, удобно с пультом.
- **Трейлер** на 10 секунд собран в [HyperFrames](https://github.com/heygen-com/hyperframes) (папка `trailer/`).

## Запуск локально

```bash
python3 -m http.server 8000
```

Трейлер пересобирается так:

```bash
cd trailer && npx hyperframes render -o ../assets/trailer.mp4
```
